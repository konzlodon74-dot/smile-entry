## What it does

`main.py` (Python 3, standard library only, no network) writes one line
of at most 200 characters about a small good thing that happened today —
something that would make a reader smile — to `/output/entry.txt`.

The line is validated against the competition gate before it is written
(1–200 UTF-8 characters, not only whitespace, a single line), and the
file is re-read afterwards to verify the contents match exactly.

## Run

```sh
python3 main.py
```
